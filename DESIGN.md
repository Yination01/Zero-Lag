# Zero-Lag design

Tokens are not locked yet. Do not invent a palette, a type scale, or chrome.

When tokens exist, they live in this file and in a single constants module.
Screens read them through a theme hook. No hardcoded hex in screens.

Until then:

- Red is a budget: destruction and warnings only.
- No emoji as feature icons.
- No AI-default purple.
- Four states on every screen: loading, empty, error, success.
- Touch targets 44 pt minimum.
- WCAG 2.1 AA contrast in both themes once themes exist.
