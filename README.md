# Zero-Lag

A mobile app that **measures network lag in real time** and **boosts device
performance** — built for mobile gamers and users on slow networks and
entry-level devices.

- **Platform:** Android-first, iOS following (React Native + Expo, TypeScript)
- **Status:** planning / scaffolding

## Docs

- [Product & Technical Plan](docs/PLAN.md) — vision, features, platform
  reality check, architecture, and milestones (M0–M6)

## Quick summary

Zero-Lag combines two engines:

1. **Network intelligence** — ping/jitter/packet-loss tests, speed tests,
   live in-game lag monitoring with alerts, and a local VPN profile for fast
   DNS + ad/tracker blocking.
2. **Performance boost** — RAM/CPU/thermal/battery vitals, memory and
   storage cleanup guidance, and a Game Mode profile (DND, wakelock, sync
   pause) with an honest before/after report.

**Next milestone:** M0 — Expo + TypeScript project scaffold with navigation
and design system, then M1 — the working lag test.
