What Zero-Lag does

Zero-Lag is an Android app for mobile gamers. It provides public-edge network readiness estimates, local readiness history, optional foreground-game detection, and an optional floating ping HUD.

Data handled on your device

Depending on permissions you choose, Zero-Lag may handle signal-related location data, device facts, a supported foreground-game package, readiness measurements, and permission state. The current version stores readiness history on the device and has no Zero-Lag backend, account system, advertising SDK, or cloud history.

Permissions

Location helps label signal conditions. Usage Access can identify a supported foreground game. Overlay access enables the floating HUD. Phone-state access helps label network type. Notification access supports the visible foreground HUD notice. You can deny optional access and continue using available features.

Your controls

You can clear local readiness history from the app, clear app storage in Android settings, or uninstall the app. Do not grant optional access on a shared device if you do not want a person using the device to see supported-game or HUD information.
