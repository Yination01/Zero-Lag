# Zero-Lag Privacy Policy

Last updated: 2026-08-29. Version 1.0.0. Have a qualified lawyer review
this before launch. This is not legal advice.

## Data we collect

In this version Zero-Lag stores data only on your device: test history,
settings, and the guest/account profile. We operate no cloud server, and no
personal data is uploaded.

## Location

Location is used on-device only, because Android only provides signal
strength (dBm) to apps holding location. Location data never leaves your
device in this version.

## Permissions

Each permission is explained in-app at request time. Special permissions
(overlay, usage access) open the matching Android settings screen.

## Accounts

Accounts are optional. Guests have full, unrestricted access. Until a cloud
backend exists and a host is named, account details form a local profile
only and are not sent anywhere.

## Future cloud features

If cloud sync or analytics are added, they will be off by default, opt-in,
and described here before they ship. There is no live host today.

## Your data

You can clear all local data by uninstalling the app or from app Settings
where supported. No server-side data exists to delete.
